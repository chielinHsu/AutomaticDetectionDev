## 證據與決定

| 面向 | 決定與證據 | 驗證 |
|---|---|---|
| 計算 | Excel 的 STDEV 使用 n−1，P/T＝6s/SPEC。CO/XO/YO 的 SPEC 為 0.35/0.25/0.25 mm，其餘 RO/LC/CX/CY/WI/BH/LH/PP 為 0.2 mm；預設以 µm 表示。SPEC、單位、倍率及預設 20% 的 P/T 門檻可以修改；公式的 6 固定。 | 獨立公式測資、SPEC 修改測試與使用者五份 CSV |
| 架構 | domain 擁有統計與資料型別；application 分析、發現指標及找共同 Box；storage 實作 CSV/JSON/匯出 port；presentation 管理背景工作與 Qt Widgets；main 組裝。沿用 Qt Concurrent、Qt Designer、主題與翻譯，不新增圖表相依。 | check-deps、qmake、Qt Test |
| 資料契約 | CSV 是多區段報表，只讀 BOX LEVEL。Component／Box 複合鍵對齊；每一份 CSV 是一次量測。Decision 不計算標準差。根目錄每份 CSV 都須成功，不能讀的檔案不跳過；不遞迴載入 PassInfo。 | 引號、非數字、重複鍵、排序、缺值測試 |
| 擴充與單位 | 新數值欄位自動成為指標。指標定義包含單位、倍率、SPEC、P/T 門檻；新指標沒有 SPEC，不能假造 P/T。Micron 與 mm 按輸出單位換算；自訂單位是明確覆寫，需要使用者確認倍率。 | 新欄位、單位與設定測試 |
| 比較母體 | 先按組計算；不把四組量測混成一組。摘要只使用各組共同、量測完整且至少兩次的 Box。Avg 是 Box 平均值的平均，其餘取最大值；P/T 差值為百分點。 | 不同 Box 集合、缺欄位、樣本不足測試 |
| 跨組折線 | 使用者選擇以資料夾為橫軸，各組摘要連線；可輸入單一 Box，只比較該框。使用獨立視窗與指標 ComboBox，同時顯示 P/T、Range。摘要沿用共同完整 Box 的最大值；同名框需 Component/Box 消歧；缺值留空不補零。擷取不可變快照，避免檢視中資料換掉。 | 指標切換、摘要與指定框、同名消歧、缺值與畫面測試 |
| 互動 | 一個資料夾顯示全部勾選指標；兩至四個資料夾同時並排，每頁以 ComboBox 選一張指標圖。關閉至一份時自動恢復全指標。比較表仍列出勾選指標。 | 原生 Qt 畫面測試 |
| 並行與生命週期 | CSV 載入及計算在背景。工作捕獲來源及不可變的舊快照；失敗／取消保留舊結果；解構先取消並等待工作結束。分析不修改 CAD 文件及復原堆疊。 | 非同步載入、失敗保留與視窗測試 |
| 保存與交付 | 有版本的 JSON 保存原始量測及指標定義，不依賴 Excel。匯出 summary.csv、details.csv 及目前可見圖表 PNG。單一檔案以 QSaveFile 寫入；多檔匯出不是交易，部分失敗可能已寫出前一個檔案。 | JSON 往返、無效版本、CSV 匯出測試 |
| 效能 | 不修改既有效能預算或重建基準線。新增功能的量測獨立記錄；大量 CSV 的容量沒有硬性承諾。 | 功能效能量測及既有回歸檢查 |

## 否決的替代方案

- 執行 VBA 或依賴 Excel COM：增加部署及全域應用程式狀態相依，且不能自然擴充指標。
- 固定四個圖表、每圖只代表一個指標：不符合「最多四個資料夾」的要求。
- 多資料夾每頁列出全部圖表：使用者明確拒絕，畫面過於擁擠。
- 缺值補零或只依 CSV 列序對齊：會低估變動，或把不同端子的數值混在一起。

## 已知界線

- 目前支援 BENANO COMPONENT REPORT 的 BOX LEVEL 數值欄位；其他報表區段需新增解析 adapter。
- 不從名稱推斷 RO 等縮寫的物理意義。CSV 原始 Fail 不代表重複性 Fail。
- 使用者仍負責選取同一工件與相同條件下的重複量測；程式無法從缺少序號的報表證明條件相同。
- 新的「數值欄位」直接支援；需由其他欄位推導的新演算法，另新增計算規則，不執行任意公式或腳本。
- 保存檔含量測快照及指標定義；不保存目前勾選欄位、分頁 ComboBox 與比較基準等暫時檢視狀態。
