## 背景

亮塊連通區的框會隨反光形狀改變，也可能抓到焊墊或其他亮區。使用者要的是影片中的樣本教學流程：先圈數個代表焊點，再搜尋全圖，產生尺寸一致的框。影片沒有展示高度資料，不能由 3D AOI 標題推論使用了高度圖。

## 決定

- R 建立樣本，不立即搜尋；F5 使用所有樣本搜尋整張原圖。S 繼續手動補框，V 編輯。
- application 新增 ISocketSampleSearcher 與 SearchSocketSamples；app 用現有 OpenCV 的 ITemplateBuilder/IPatternSearcher 組裝。presentation 不引用 OpenCV。
- 依原圖灰階外觀與少量周邊特徵作模板匹配；輸入可為 RGB／灰階，沒有高度圖需求。
- 使用者選取範圍是主體框，周邊特徵只用於比對。所有新結果一律使用第一個樣本的寬高；匹配位置依現有 port 契約回報主體中心。
- 每個樣本可涵蓋不同明暗或左右外觀。跨樣本以分數與重疊去重；只接受達門檻的匹配，不作低分晶格補漏。
- 預設相似度 90%，UI 可調 50–99%；是相關比對分數，不是缺陷合格率。需要人工檢查、修改或刪除。
- Sample 元件保留於既有 Board，配方仍為 JSON v3；Recipe.params.minScore 保存門檻。存讀後可用原圖重建範本，第一樣本決定輸出尺寸。
- 重搜取代舊 Auto 結果，保留樣本與手動補框；空結果／錯誤保留既有資料。背景工作沿用世代與取消規則。
- 限制 16 個樣本、結果與文件容量，避免任意大量匹配；平坦或無效樣本明確拒絕。

## 未採用

- 沿亮塊外形決定每個結果大小：不符合使用者的統一尺寸需求。
- 直接套 R07 的低分驗證／推算框：使用者正關切誤框，第一版先只保留影像實際達門檻的結果；不修改 R07 的規則。
- 新增高度圖或深度模型：沒有這些來源資料，也不是本次教樣本需求。

## 限制

主流程先固定角度與比例；外觀不同的焊點需教代表性樣本，不能保證任意光照／旋轉都辨識。自動結果尺寸一致，之後仍允許人工單框修改。原圖另存，配方不嵌入原圖。相似度與人工標準答案不同，真實圖沒有完整標註前不宣稱精確率／召回率。
