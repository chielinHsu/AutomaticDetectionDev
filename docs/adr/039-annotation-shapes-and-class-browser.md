# ADR-039：標註形狀意圖與依類別收合查詢

- 日期：2026-10-30
- 狀態：採用
- 計畫：R09.12、R09.13

## 形狀意圖

使用者回報用矩形工具建立的框，拉角點卻變成多邊形。原資料只記 points，所有頂點都自由移動，無法知道建立方式。

在 pcb-learning-project v1 標註新增可選 shape=rectangle／polygon。矩形四角沿原本正交軸縮放，固定對角、同步另外兩角，長寬不綁固定比例；旋轉矩形同樣保持直角。預覽與提交共用 resized_vertex；放開才提交，超界拒絕，最短邊 2 原圖像素，可跨越固定角翻轉而不退化。

使用者明確按「多邊形頂點」才改為自由頂點；轉換不改原輪廓。按「矩形拉伸」可將多邊形轉成最小外包旋轉矩形，超界拒絕，Undo 可復原。輪廓工具即使畫出四個直角，仍保存 polygon 意圖。

舊標註缺少 shape 時，只在幾何確實為矩形時使用矩形編輯，其餘保持多邊形。不在開檔時新增欄位或改座標；使用者編輯後才保存意圖。資料集依原 polygon／OBB 匯出，模型契約不改。

## 查詢與漸進顯示

把平面表格改成左側類別樹，根節點顯示類別與數量，預設收合。搜尋中文／英文類別、目前 #編號、可選名稱 name；搜尋暫展開命中群組，清除後還原原來狀態。搜尋同步篩選畫面，但不改文件。類別節點不作為元件刪除目標。

單擊選框，雙擊或 Enter 放大定位；可全部展開／收合、隱藏整個清單。預設只有選取項顯示完整標籤，可勾顯示全部標籤。所有框線仍保留高對比描邊。

名稱由使用者自行輸入，不猜測實際 R22／U1 等 BOM 代號。編號依目前清單排序，刪除會重排；固定查找可用名稱。name 是 v1 可選純文字欄位，最長 128 字元，支援 Undo 及存讀。沒有引入永久 ID，避免在載入舊資料時擅自改動內容。

## 驗證與範圍

六項形狀測試包含四角、旋轉、跨角、邊界、舊檔、轉換、滑鼠即時預覽、Undo 與存讀。五項類別清單測試包含收合狀態、搜尋與畫面、名稱、放大定位、刪除安全及標籤。加上既有流程共 32 項通過。

本次不改 C++ Socket／R07、訓練方式或推論輸出。既有視窗仍有使用者操作及未儲存內容；工具偵測輸入後停止重開，不用舊備份覆蓋，待使用者儲存後重新啟動。
