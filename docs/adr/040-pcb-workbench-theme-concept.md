# ADR-040 PCB 標註工作台雙主題與三欄視覺概念

- 日期：2026-10-30
- 決定者：使用者（工作台方向、支援雙主題、預設深色）；Codex (gpt-6.1-sol)（概念與操作規格）
- 狀態：採用於設計概念；尚未實作至執行介面

## 背景

使用者提供配置與淺深色參考圖，要求第二階段標註元件採工程工作台方向，並確認預設深色、同時支援淺色。現有 tools/pcb_dl/guided_ui.py 已有五步與可收合清單；ui_theme.py 依系統 palette 判定深淺，尚無本次設計的明確主題切換器。

## 決定

概念使用左側圖片／類別／清單、中央 PCB、右側選取屬性；共用同一份配置與標註色。首次深色、可切淺色並記住偏好是後續實作條件，切換不得改標註／影像／選取／縮放。

類別色與選取狀態分離，幾何有效與人工整圖審核分離，存檔狀態沿用現有明確儲存行為；無校正時僅顯示像素單位。規格與概念圖在 [workbench/DESIGN.md](../steps/R09-deep-learning-cad/workbench/DESIGN.md)。

## 否決的替代方案

- 僅依系統主題：無法保證使用者指定的首次深色與可自行切換。
- 每個框依編號給不同色：難以快速辨認同一類元件。
- 用幾何檢查代表人工審核：不能證明圖中所有元件已標註。

## 後果

本次只交付視覺概念及規格，不改 PySide6、C++／Rust 或資料契約，也不重開目前含未儲存調整的視窗。ADR-037–039 的程序隔離、形狀與查詢規則繼續有效。程式改版、主題切換持久化、互動與 DPI 驗證仍須後續實作與實測。
