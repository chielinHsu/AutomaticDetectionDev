## 配置與視覺

| 區域 | 內容與優先順序 |
|---|---|
| 頂部 | 專案、已儲存／未儲存、Undo／Redo、開啟／儲存、深色／淺色選擇 |
| 五步導覽 | 載入圖片 → 標註元件 → 設定檢測框 → 訓練模型 → 產生與儲存；第二步藍色高亮 |
| 左側約 18% | 圖片縮圖、目前圖片的類別統計、依類別收合的標註清單；搜尋類別／名稱／編號 |
| 中央約 59% | PCB 影像、縮放與適配、互斥工具列、情境提示；保留最大可見範圍 |
| 右側約 23% | 僅目前選取標註的類別、名稱、形狀、幾何、裁切預覽、幾何檢查；沒有選取時顯示簡短提示 |
| 底部 | 目前工具、標註數、原圖尺寸與縮放、存檔狀態；下一步主要按鈕 |

兩種主題共用配置、字級、間距、圖示與語意色；切換時不更動影像像素、縮放、選取、草稿或標註資料。首次啟動深色，之後記住使用者選擇，是後續實作的驗收條件。畫布底色與面板底色分開，避免修改照片色彩。

以 8px 為主要間距，控制項約 36–40px 高；文字採系統繁中字型，數值可用等寬字型。主按鈕使用藍色，面板使用平面色與細邊界。1366×768、小視窗及高 DPI 的可用性須在實作時量測；側欄可收合且可調寬，不靠縮小文字維持三欄。

## 標註與資料一致性

- 類別固定色：電阻藍、電容橙、電感綠、IC 紫、二極體紅、電晶體青、連接器黃、其他灰；同類別的所有框一致，不因編號改色。
- 選取使用加強外框、白色把手與完整標籤，不改類別色；一般框只顯示短編號，完整標籤按需開啟。保留 ADR-039 的類別收合與查詢。
- 不以顏色作唯一資訊：清單、標籤與檢查狀態另有文字／符號。警告不覆寫類別顏色。
- 概念使用四個標註：電阻 2、電容 1、IC 1；選取 #02 電阻，名稱 R22。清單、畫布標籤、右側類別與裁切預覽必須指向同一物件。
- 範例影像 z0.png、5120×4096、1/3、4 個標註；其餘圖片 2 與 1 個。類別統計是目前圖片，不與整個專案的總數混用。
- 幾何統一採中心 X／Y、局部 W／H、角度；概念值 1248、986、82、46、0°，屬示意數字，不是使用者的真實標註。
- 矩形保持直角；轉成多邊形需明確操作，可復原。多邊形狀態顯示頂點編輯，避免把外包框當成原始輪廓。
- 沒有實體校正時僅用 px，禁止自行推測 mm 比例尺。

## 操作與防誤觸

1. 左側選圖片與新增標註的類別；沒有選取物件時右側不顯示上一筆可刪除的資料。
2. 工具一次只啟用一個。選取可移動／拉伸；畫矩形與畫輪廓互斥，情境提示跟隨目前工具。切換圖片時未完成草稿須有清楚處置，不能默默丟棄。
3. 選框後右側同步該框；欄位提交形成一筆 Undo，超界、尺寸無效或輪廓自交時拒絕並說明。Esc 取消草稿，Delete 只作用在畫布／清單焦點；文字欄位的 Delete 繼續編輯文字。
4. 儲存目前專案使用既有明確存檔流程；不在概念中暗示已實作自動儲存。失敗保持未儲存狀態，另存取消不得關閉專案。
5. 「幾何有效」只表示類別／尺寸／範圍檢查；「這張圖的元件皆已標註並檢查」是使用者人工確認，不能根據幾何檢查自動勾選。修改標註後撤銷審核。
6. 下一步進入設定檢測框；整圖審核是匯出訓練資料的條件，未審核仍可設定 CAD 規格。進度未儲存時導航保留記憶體內容，不默默丟失。

右側「儲存進度」是次要動作，底部「下一步：設定檢測框」是主要動作。「完成此圖審核」只有在人工勾選後才可操作；不使用含義不明的「完成標註」混合存檔、審核和導航。

## 視覺生成與 UX 審查分開

概念圖使用內建 imagegen，提示詞保存在 [prompts.md](prompts.md)。使用者圖 3 為深色配置與 PCB 照片的視覺參考，淺色版由同一深色結果轉換，以維持構圖。生成圖內文字／數字仍須以本規格為準，不視為實際軟體截圖或可執行功能。

本機未找到使用者敘述提及的 frontend-design、ui-ux-pro-max-skill 或既有 DESIGN.md，也未提供文章連結；本次未聲稱已讀取該文章或執行那些 skill。本檔是本次新增的局部一致性規格。

UX 審查以靜態流程檢視進行，尚無使用者測試。後續實作需驗證：空選取、類別群組選取、草稿取消、文字 Delete、超界回復、Undo／Redo、審核失效、取消另存、主題切換保留狀態、小視窗與高 DPI。現有 R09 的 32 項通過紀錄來自前次實作，不是這次新測試。

## 色彩規格

色票與文字組合在 [theme-tokens.json](theme-tokens.json)。最低要求一般文字對比 4.5:1，控制邊界與焦點指示 3:1；標註框面對任意照片背景，仍須雙描邊與文字標籤，不能只靠色票對比推論可讀性。色票檢查只驗證指定組合，不等同於生成圖的逐像素可及性或正式 UI 驗收。
