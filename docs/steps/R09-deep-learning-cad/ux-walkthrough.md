# 第一次使用：照上方五步操作

## 1 載入圖片

按「載入 PCB 圖片」，或「開啟標註專案」。已經有模型可用「我已有模型，直接產生 CAD」。目前圖片可在畫布上方切換。

## 2 標註元件

這一步是在教模型；每畫一次只新增一個標註，不會立即搜尋全圖。

1. 選「電阻」「電容」「IC」或新增自己的封裝類別。
2. 用滾輪放大元件，按「開始畫矩形框」。
3. 在元件左上角按住左鍵，拖到右下角再放開。框住元件本體，避開白色絲印及鄰近物件。
4. 畫完會出現帶編號的橘黃框和新增提示。白框表示目前選取；拖動白色把手可調整。
5. 選錯類別：點選框、在右邊改類別，再按「將選取框改為上方類別」。要刪除時，點選框或清單列，按 Delete；Ctrl+Z 可復原。游標在文字欄位時 Delete 只刪文字。
6. 標完整張並檢查後勾選完成；按「儲存標註進度」。

輪廓工具沿元件逐點點擊，Enter 完成、Backspace 回退、Esc 取消。範圍太小時程式會提示先放大，不建立看不清楚的意外標註。

### 矩形與多邊形的調整

矩形工具建立的標註，拖角點會保持四個直角，長寬可各自拉伸；拖曳過程會顯示預覽。選取後右側的「矩形拉伸／多邊形頂點」會顯示目前模式。

需要自由調整頂點時按「多邊形頂點」。已拉歪的舊框可明確按「矩形拉伸」轉回外包矩形；這會改輪廓，可 Ctrl+Z 復原。開啟舊標註時不會擅自改座標。

### 大量元件的查詢

- 左側「元件類別」依電阻／電容／IC 或自訂類別分組，顯示數量，預設收合。點箭頭展開，也有「展開全部／收合全部」。
- 搜尋類別、使用者自訂名稱或 #編號，例如「IC」「電容」「R22」「#12」。搜尋會同時篩選清單與框線；按搜尋框內的清除按鈕恢復全部，原來的收合狀態會保留。
- 單擊子項選框，雙擊或 Enter 放大定位；「適配視窗」回到全圖。點類別標題不會留下上一個元件作為刪除目標。
- 預設只有選取項顯示完整標籤；需要全部文字時勾「顯示全部框的標籤」。上方「隱藏元件清單」可收掉整個左欄。
- 選取後左下可填名稱再按「套用名稱」。R22／U1 必須由你確認，程式不會自動猜測。#編號會隨刪除重排；固定查找請填名稱。

## 3 設定檢測框

點選一個標註，再按「從目前選取的元件帶入尺寸」，檢查每類 W/H 與子窗比例。這是 CAD 規格，不能只因模型看見不同反光就改變。

## 4 訓練模型

頁面會顯示還有幾張未檢查及幾個獨立來源。設定目前圖片的板子／批次與用途；同板的 RGB／Z 照片不可跨用途。完成條件前匯出按鈕停用並說明原因。準備好後匯出資料、選 OBB 或分割，再開始訓練。回合數等進階值預設收合。

## 5 產生與儲存

載入訓練完成的 model.json，再按整張辨識或圈選辨識範圍。綠框為 CAD、青框為子窗、粉框為模型觀察輪廓。選取後可改單框幾何，確認結果後按「儲存 CAD 配方」。

Ctrl+S 儲存目前文件；Ctrl+Shift+S 另存標註。標註專案與 CAD 配方是不同文件。尚未完成標註與正式模型時，不會自動產生可信的 PCB 辨識結果。
