# Socket 區域 CAD 操作

執行新版 `StartSocketRegionCAD.cmd`，確認工具列顯示「區域 CAD 註冊 R」與「全圖 CAD 註冊 F5」。舊 SampleSearch 執行包不包含此流程。

1. 載入 Socket 照片。
2. 按 R，拖出含數個端點與焊墊的選區，放開後直接產生 CAD。
3. 按 F5 註冊整張圖。第一次成功後沿用同一 CAD 尺寸；需要指定尺寸時取消自動估計，填 CAD W/H。
4. 按 V 選取並拖移或調整大小，按 S 手動補框。可刪除、復原與重做。
5. 儲存 JSON 配方，照片保留原路徑；開啟配方可繼續編輯。

外框是定位範圍，內框是子檢測窗。CAD-L/R 表示焊墊位於端點左/右。多個物件共用規格，單框改尺寸不會連帶修改其他框。重註冊保留人工修改。

此版本不用範本比對，也不用高度圖；以 Socket 水平端點的結構規則辨識。結構品質不是 AI 機率，不會判斷焊接 OK/NG。請檢視誤框與漏框後再儲存；通用 PCB 多類模型在 R09。
