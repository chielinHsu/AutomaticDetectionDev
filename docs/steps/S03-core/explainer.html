S03 — 系統核心：ports、use case、工作執行器

核心沒有畫面、不認識 OpenCV 或 HALCON。這一頁讓你動手看四件事：換 back end 時 use case 一個字不改；有人偷 include 函式庫時依賴檢查怎麼擋；新舊搜尋同時在跑時「最新的贏」；分數門檻只是重新過濾、不必重新搜尋。標「示意」的是動畫，其餘文字與數字是程式或工具真的輸出（執行後逐字抄下，來源見各卡片）。
