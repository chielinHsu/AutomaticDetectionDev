S10：我們怎麼證明程式夠快——效能 harness 與回歸閘門

這一頁就是 scripts/dev/perf.ps1 產生的互動式效能報表：一次 test.ps1 -Perf 的所有結果（搜尋矩陣、T5 端到端、UI 與互動、A/B、各 back end）彙整成一份執行紀錄，和基準線（同一台機器幾次執行的範圍）與預算（perf/budgets.json）比。下面嵌的是量測時的實際資料；也可以載入別次的 perf/results/*.json。拖動「回歸的門檻」可以看門檻怎麼影響判定。

判定

搜尋矩陣（perf_matrix）：各階段的切片

每一格是 use case 端到端（中位數），顏色是四個階段：範本 種子搜尋 晶格 視窗驗證。用上面的 back end 篩選；按欄名排序。

所有指標

值：有預算的指標看 p95（越大越好的看最小值）；基準線的欄位是幾次執行的中位數範圍。條：值對預算（紅 ＝ 超標、琥珀 ＝ 已知的超標）。

測試執行檔的狀態

跳過不是通過：有 SKIP 的執行檔列成「未驗證」（例如 HALCON 讀不到授權）；XFAIL 是已知、待修的問題（修好會變成 XPASS ＝ 失敗）。
